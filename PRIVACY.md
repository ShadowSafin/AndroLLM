# Privacy Policy

**Last updated:** August 2026  
**App version:** 1.0.0  
**Package name:** `io.androllm.app`

---

## Overview

AndroLLM is designed around a simple principle: **your data stays on your device**. This privacy policy describes what data we collect, what data you control, and how we protect it.

---

## Data That Stays on Your Device

### Local Inference Data
When you run models locally (GGUF via llama.cpp):
- Model weights and binaries — stored in your app's private storage
- Conversation history — stored in the local Room database
- Generated responses — ephemeral during generation, persisted locally after
- Memory embeddings and vectors — stored in a local SQLite database
- All computation happens on your device's CPU/GPU — no network transmission

### Voice Assistant Data
When using the offline voice assistant:
- Audio captured from your microphone is processed entirely on-device
- Wake word detection, speech recognition, and text-to-speech use bundled ONNX models
- No audio is transmitted to any server
- The voice service runs as a foreground service with an ongoing notification

### Application Preferences
Stored locally via DataStore:
- Theme preference (light/dark/system)
- Language selection
- Developer mode toggle
- Storage path configuration
- Voice assistant settings (enabled, sensitivity, battery saver mode)

---

## Data That May Leave Your Device

### Cloud Provider Data
When you choose to use a cloud AI provider:
- Your messages are sent to the provider's API endpoint
- API keys are encrypted with Android Keystore before storage; decrypted only at request time
- You control which provider to use and can disable cloud mode entirely
- We do not log, store, or transmit your messages to any third party beyond the provider you select

### Firebase Authentication (Optional)
When you sign in via Google or GitHub:
- Authentication tokens are managed by Firebase Authentication
- Profile information (display name, email) is stored in Firebase Firestore
- Account deletion removes all associated data
- Authentication is optional — guest mode is always available

### Network Requests
- Model downloads from HuggingFace (HTTPS only)
- Provider model discovery via `/v1/models` endpoint
- Health checks against configured providers
- All network traffic uses HTTPS; cleartext HTTP is disabled

---

## What We Do NOT Collect

- ❌ Conversation content (when using local mode)
- ❌ Voice audio recordings
- ✅ No analytics tracking service
- ✅ No crash reporting to external services (crash logs are local-only)
- ✅ No usage statistics sent to third parties
- ✅ No advertising identifiers

## Your Rights and Controls

| Control | Location |
|---|---|
| Delete all conversations | Settings → Storage → Clear cache |
| Delete all memories | Settings → On-device Memory → Delete all |
| Disable voice assistant | Settings → Voice Assistant → Toggle off |
| Disable cloud mode | Settings → Cloud Providers → Toggle off |
| Remove an API key | Settings → Cloud Providers → Edit provider |
| Delete your account | Firebase console (for authenticated users) |
| Export conversation history | Chat drawer → Export conversation |
| Revoke microphone permission | Android Settings → Apps → AndroLLM → Permissions |

---

## Data Retention

### Conversations
Conversations are retained indefinitely until you delete them. There is no automatic cleanup.

### Memory Data
Memories persist until you delete them or disable the memory system. Summaries generated by the memory system are stored alongside the memories they summarize.

### Voice Settings
Voice settings are deleted when you uninstall the app (stored in DataStore).

### Cache
Temporary files (download progress, model validation caches) are cleaned automatically.

---

## Security Measures

- **Encryption at rest**: API keys use AES-256/GCM via Android Keystore
- **Database security**: Room databases are stored in the app's private sandbox (`/data/data/io.androllm.app/`)
- **Network security**: All HTTP traffic requires TLS 1.2+; cleartext is disabled
- **Permissions minimalism**: Only required permissions are requested (microphone, storage, internet)
- **Open source**: The full source code is available for security audit
